یادمه در صحبتهای بالا گفتی از نظر تو واگرایی مثبت یا مثبت مخفی در آیتمهای زیر 
MFI,CCI,RSI,MACD
واقعا ایده آل و ترجیح توست. درسته؟ چیزی که میتواند قدرتمندانه آغاز روند را تایید نماید. اگر اینطورست فیلتری بنویس که اگر همزمان این 4 واگرایی مثبت یا مخفی مثبت برای سهمی روی داد چه در حالت انلاین چه خارج تایم بازار همه چیز نمایان گردد. با توضیح و انتخاب نام مناسب . چون تو بسیار امید داشتی روی آن
-----------------

بله؛ **در چارچوبی که تا اینجا با هم ساخته‌ایم، این ترکیب چهارگانه یکی از مهم‌ترین ترکیب‌های واگرایی برای من است**:

**MFI + CCI + RSI + MACD**

اما یک اصلاح مهم: من آن را «تأیید قطعی شروع روند» نمی‌نامم. واگرایی ابزار بسیار قدرتمندی برای تشخیص **تغییر مومنتوم و احتمال تغییر فاز** است، ولی به‌تنهایی تضمین‌کننده رشد نیست. ارزش اصلی زمانی ایجاد می‌شود که هر چهار مورد روی **یک ساختار قیمتی مشترک** هم‌جهت شوند و بعد با حجم، تابلو، حمایت و رفتار قیمت تأیید شوند.

با توجه به چیزی که الآن خواستی، فیلتر جدید را طوری می‌سازم که:

* هر چهار اندیکاتور باید واگرایی مثبت **Regular Bullish** یا **Hidden Bullish** داشته باشند.
* واگرایی‌ها نسبت به **همان دو Pivot قیمتی** بررسی شوند.
* ترکیب‌های مختلف مجاز باشند؛ مثلاً MFI و RSI واگرایی مثبت عادی داشته باشند ولی CCI و MACD واگرایی مثبت مخفی.
* هر چهار مورد باید همزمان تأیید شوند.
* بر مبنای داده تاریخی کار کند و بنابراین **خارج از ساعت بازار** نیز قابل اجراست.
* در زمان بازار نیز با آخرین Pivot تأییدشده قابل استفاده است.
* عمداً از Pivot تأییدنشده استفاده نمی‌کنم؛ چون در حالت آنلاین باعث سیگنال‌های کاذب و تغییرپذیر می‌شود.

# فیلتر شماره جدید — **D4C**

## Four-Divergence Confluence Engine

این فیلتر را جدا از DIVE-6X نگه می‌داریم.

**DIVE-6X:**
شش مؤلفه → بسیار نادر و بسیار سخت‌گیر

**D4C:**
چهار مؤلفه کلیدی → تمرکز روی کیفیت واگرایی‌های MFI/CCI/RSI/MACD

به نظرم D4C از نظر کاربرد عملی حتی می‌تواند مهم‌تر از DIVE-6X باشد، چون الزام Volume و Stochastic را حذف می‌کند و در عوض روی چهار مؤلفه‌ای متمرکز می‌شود که برای تشخیص تغییر مومنتوم بسیار معنادارند.

---

```javascript

xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

true==function()
{
    /*
    ================================================================
    D4C
    FOUR-DIVERGENCE CONFLUENCE ENGINE

    MFI + CCI + RSI + MACD

    هدف:
    شناسایی سهم‌هایی که روی یک ساختار Pivot مشترک،
    هر چهار اندیکاتور دارای واگرایی صعودی باشند.

    انواع واگرایی مجاز:

    1) Regular Bullish Divergence
       قیمت: کف جدید پایین‌تر
       اندیکاتور: کف بالاتر

    2) Hidden Bullish Divergence
       قیمت: کف بالاتر
       اندیکاتور: کف پایین‌تر

    هر چهار اندیکاتور باید یکی از این دو نوع واگرایی
    را نسبت به همان دو Pivot قیمتی نشان دهند.

    کاربرد:
    WATCHLIST / REVERSAL / EARLY TREND DETECTION

    قابل استفاده:
    - خارج از بازار
    - حین بازار با آخرین Pivot تاییدشده

    نکته:
    سیگنال خرید قطعی نیست.
    ================================================================
    */


    // ------------------------------------------------
    // حداقل دیتای مورد نیاز
    // ------------------------------------------------

    if(typeof [ih]=="undefined")
        return false;

    if([ih].length<45)
        return false;


    var len=Math.min([ih].length,70);


    // ------------------------------------------------
    // DATA
    // ------------------------------------------------

    var P=[];
    var H=[];
    var L=[];
    var V=[];
    var TP=[];

    for(var i=0;i<len;i++)
    {
        if(typeof [ih][i]=="undefined")
            return false;

        P[i]=[ih][i].PClosing;
        H[i]=[ih][i].PriceMax;
        L[i]=[ih][i].PriceMin;
        V[i]=[ih][i].QTotTran5J;

        if(P[i]<=0 || H[i]<=0 || L[i]<=0)
            return false;

        TP[i]=(H[i]+L[i]+P[i])/3;
    }


    // ------------------------------------------------
    // EMA
    // ------------------------------------------------

    var EMA=function(arr,period)
    {
        var out=[];

        var alpha=2/(period+1);

        out[0]=arr[0];

        for(var i=1;i<arr.length;i++)
        {
            out[i]=
                alpha*arr[i]+
                (1-alpha)*out[i-1];
        }

        return out;
    };


    // ------------------------------------------------
    // RSI
    // ------------------------------------------------

    var RSI=[];

    for(var i=0;i<len;i++)
    {
        var gain=0;
        var loss=0;

        var start=Math.min(len-1,i+13);

        for(var j=i;j<start;j++)
        {
            var ch=P[j]-P[j+1];

            if(ch>0)
                gain+=ch;
            else
                loss-=ch;
        }

        if(loss==0)
            RSI[i]=100;
        else
        {
            var rs=gain/loss;

            RSI[i]=100-(100/(1+rs));
        }
    }


    // ------------------------------------------------
    // MFI
    // ------------------------------------------------

    var MFI=[];

    for(var i=0;i<len;i++)
    {
        var pos=0;
        var neg=0;

        var start=Math.min(len-1,i+13);

        for(var j=i;j<start;j++)
        {
            var money=TP[j]*V[j];

            if(TP[j]>TP[j+1])
                pos+=money;

            if(TP[j]<TP[j+1])
                neg+=money;
        }

        if(neg==0)
            MFI[i]=100;
        else
        {
            var ratio=pos/neg;

            MFI[i]=100-(100/(1+ratio));
        }
    }


    // ------------------------------------------------
    // CCI
    // ------------------------------------------------

    var CCI=[];

    for(var i=0;i<len;i++)
    {
        var start=Math.min(len-1,i+19);

        var sum=0;
        var count=0;

        for(var j=i;j<=start;j++)
        {
            sum+=TP[j];
            count++;
        }

        var mean=sum/count;

        var dev=0;

        for(var j=i;j<=start;j++)
            dev+=Math.abs(TP[j]-mean);

        dev=dev/count;

        if(dev==0)
            CCI[i]=0;
        else
            CCI[i]=(TP[i]-mean)/(0.015*dev);
    }


    // ------------------------------------------------
    // MACD HISTOGRAM
    // ------------------------------------------------

    var ema12=EMA(P,12);
    var ema26=EMA(P,26);

    var MACD=[];

    for(var i=0;i<len;i++)
        MACD[i]=ema12[i]-ema26[i];

    var signal=EMA(MACD,9);

    var MACDH=[];

    for(var i=0;i<len;i++)
        MACDH[i]=MACD[i]-signal[i];


    // ------------------------------------------------
    // PIVOT LOW
    //
    // فقط Pivot تاییدشده استفاده می‌شود.
    // این موضوع برای استفاده آنلاین بسیار مهم است.
    // ------------------------------------------------

    var pivotLow=function(i)
    {
        if(i<3 || i>len-4)
            return false;

        return(
            L[i]<=L[i-1] &&
            L[i]<=L[i-2] &&
            L[i]<=L[i+1] &&
            L[i]<=L[i+2]
        );
    };


    // ------------------------------------------------
    // پیدا کردن دو Pivot Low اخیر
    // ------------------------------------------------

    var recent=-1;
    var old=-1;

    for(var i=3;i<len-3;i++)
    {
        if(pivotLow(i))
        {
            if(recent==-1)
                recent=i;
            else
            {
                old=i;
                break;
            }
        }
    }


    if(recent==-1 || old==-1)
        return false;


    // فاصله بسیار کم بین دو Pivot
    // ارزش تحلیلی واگرایی را کاهش می‌دهد.

    var gap=old-recent;

    if(gap<5)
        return false;


    // ------------------------------------------------
    // Regular Bullish
    //
    // Price:
    // Lower Low
    //
    // Indicator:
    // Higher Low
    // ------------------------------------------------

    var regularBull=function(ind)
    {
        return(
            L[recent]<L[old] &&
            ind[recent]>ind[old]
        );
    };


    // ------------------------------------------------
    // Hidden Bullish
    //
    // Price:
    // Higher Low
    //
    // Indicator:
    // Lower Low
    // ------------------------------------------------

    var hiddenBull=function(ind)
    {
        return(
            L[recent]>L[old] &&
            ind[recent]<ind[old]
        );
    };


    // ------------------------------------------------
    // هر دو نوع واگرایی برای هر اندیکاتور
    // ------------------------------------------------

    var D_MFI=
        regularBull(MFI) ||
        hiddenBull(MFI);

    var D_CCI=
        regularBull(CCI) ||
        hiddenBull(CCI);

    var D_RSI=
        regularBull(RSI) ||
        hiddenBull(RSI);

    var D_MACD=
        regularBull(MACDH) ||
        hiddenBull(MACDH);


    // ------------------------------------------------
    // CONFLUENCE
    //
    // هر چهار مورد باید تایید شوند.
    // ------------------------------------------------

    if(
        D_MFI &&
        D_CCI &&
        D_RSI &&
        D_MACD
    )
        return true;


    return false;

}()
```

## این فیلتر دقیقاً چه چیزی را شکار می‌کند؟

فرض کن قیمت سهم این ساختار را ساخته:

**سناریوی Regular Bullish**

```text
قیمت

Pivot 1       Pivot 2
  \             \
   \             \
    \             \____
          ↓
      کف پایین‌تر
```

ولی همزمان:

```text
MFI       کف بالاتر
CCI       کف بالاتر
RSI       کف بالاتر
MACD      کف بالاتر
```

این وضعیت از نظر مومنتوم بسیار جالب است.

یعنی قیمت هنوز ضعف ظاهری دارد، اما **چهار اندازه‌گیر مختلف از مومنتوم دیگر همان ضعف قیمت را تأیید نمی‌کنند.**

---

### حالت Hidden Bullish

در حالت مخفی، ساختار برعکس است:

```text
قیمت:
Pivot 1        Pivot 2
   \              /
    \____________/
       کف بالاتر


اندیکاتورها:
کف پایین‌تر
```

یعنی قیمت یک **Higher Low** ساخته، ولی اندیکاتورها کف پایین‌تری ساخته‌اند.

این حالت بیشتر می‌تواند نشانه **ادامه روند صعودی موجود** باشد، نه الزاماً شروع یک روند جدید.

به همین دلیل D4C دو نوع واگرایی را مجاز کرده ولی آنها را در تحلیل بعدی باید از هم تفکیک کنیم.

---

# چرا این چهار تا را انتخاب کردم؟

### 1. MFI

فقط قیمت را نگاه نمی‌کند و اطلاعات قیمت/حجم را وارد سنجش جریان پول می‌کند.

### 2. CCI

برای تشخیص تغییرات مومنتوم و فاصله قیمت از رفتار معمول خود مفید است.

### 3. RSI

یک سنجه کلاسیک مومنتوم است و واگرایی آن می‌تواند کاهش قدرت حرکت قبلی را نشان دهد.

### 4. MACD

برای تغییر فاز مومنتوم و رابطه روند کوتاه‌تر و بلندتر بسیار مهم است.

بنابراین وقتی **هر چهار مورد مستقل از یکدیگر یک پیام مشابه بدهند**، ارزش سیگنال از یک واگرایی منفرد بیشتر می‌شود.

اما باز هم تأکید می‌کنم:

**چهار واگرایی ≠ تضمین رشد.**

## آنلاین یا آفلاین؟

**هر دو.**

### خارج بازار

داده‌های تاریخی را بررسی می‌کند و آخرین ساختار Pivot تأییدشده را پیدا می‌کند.

### داخل بازار

روی آخرین Pivot تأییدشده کار می‌کند.

اما یک محدودیت بنیادی وجود دارد:

> **واگرایی مبتنی بر Pivot را نمی‌توان بدون تأخیر به‌صورت واقعی و بدون ریسکِ تغییر سیگنال تشخیص داد.**

چون برای اینکه بفهمیم یک کف واقعاً Pivot بوده، باید چند کندل بعدی آن را تأیید کنند.

این ضعف کد نیست؛ ماهیت تحلیل Pivot است.

بنابراین من ترجیح می‌دهم **سیگنال کمی دیرتر ولی تأییدشده** باشد تا اینکه با Pivot جاری سیگنال زودهنگام و ناپایدار بدهیم.

**D4C-Pro**

* فاصله دو Pivot چقدر است؛
* عمق اصلاح چقدر است؛
* واگرایی چند روز است که فعال شده؛
* آیا قیمت بعد از Pivot شروع به ساخت Higher High کرده؛

ولی فعلاً **D4C را دست نمی‌زنم**. چون تو گفتی این فیلترها را جداگانه آزمایش و بازخوردگیری می‌کنی و بهتر است از ابتدا آن‌قدر شرط اضافه نکنیم که ندانیم کدام قسمت واقعاً ارزش ایجاد کرده است.
