حالا در راستای فیلترهای فوق دو فیلتر مجزا از تو میخواهم که به صورت جداگانه به من نمایش بدهی . ببین یکی از فیلتر ها زمانی باشد که کندل سه سرباز سفید داشته باشیم. و فیلتر بعدی فیلتر ستاره صبحگاهی یا همان مورنینگ استار باشد. مثل بالا این فیلترها مجوز خرید نمیدهند فقط سهم را در واچ لیست قرار میدهند. ضمنا نظرت را راجع به تصمیم من بگو. کامل توضیح بده اگر این سهام در خروجی فیلتر قرار گرفتند نوید چه چیزی را میدهند آیا اگر سهمی ابتدا در فیلترهای واگرایی و  این فیلترهای کندلی ظاهر شدند اگر توسط فیلترهای حرفه ای و عملیاتی که قبلا نوشتیم هم پس از ان تایید شوند میتواند اعتبار انها را افزایش دهد
--------------------

بله. تصمیم تو را **تأیید می‌کنم، با یک اصلاح مهم**: این دو فیلتر را نباید فیلتر خرید بدانیم؛ آنها باید **فیلتر الگوی کندلی برای تولید سرنخ** باشند. بهترین استفاده‌شان دقیقاً همان چیزی است که گفتی: ابتدا وارد Watchlist شوند و بعد فیلترهای ساختاری، تابلو، نقدشوندگی، سابقه و مومنتوم آنها را تأیید یا رد کنند.

در واقع معماری خوبی می‌شود:

**واگرایی → الگوی کندلی → تأیید عملیاتی → بررسی انسانی**

و اگر مثلاً یک سهم هم‌زمان در D4C و Morning Star ظاهر شود و بعد RRE/SRS یا سایر فیلترهای عملیاتی آن را تأیید کنند، اعتبار آن **بیشتر می‌شود**؛ نه اینکه احتمال موفقیت به‌صورت قطعی یا خطی افزایش پیدا کند.

# فیلتر شماره جدید

# **WS-3 — Three White Soldiers Watchlist**

### مأموریت

این فیلتر به دنبال **سه کندل صعودی متوالی و باکیفیت** است که نشان دهد فشار خرید در سه جلسه معاملاتی متوالی بر فروشندگان غلبه کرده است.

اما یک نکته مهم:

من نسخه ساده‌ی «سه کندل سبز پشت سر هم» نمی‌خواهم. آن فیلتر بیش از حد خام است.

در WS-3 موارد زیر بررسی می‌شود:

* هر سه کندل صعودی باشند.
* بدنه هر سه کندل معنادار باشد.
* بسته‌شدن هر کندل بالاتر از قبلی باشد.
* قیمت بازشدن کندل بعدی در محدوده منطقی بدنه کندل قبلی باشد.
* سایه بالایی بیش از حد بزرگ نباشد.
* کندل سوم ضعیف و سایه‌دار نباشد.
* رشد سه کندل به شکل غیرمنطقی و انفجاری نباشد.
* بدنه‌ها نسبت به دامنه همان کندل ارزیابی شوند، نه با عدد ثابت.

این آخری مهم است؛ چون همان‌طور که خودت درباره دامنه‌های مختلف بازار گفتی، **نباید کد را با «مثبت ۳٪» یا «منفی ۲٪» کور کنیم.**

```javascript

true==function()
{
    /*
    ================================================================
    WS-3
    THREE WHITE SOLDIERS WATCHLIST

    هدف:
    شناسایی الگوی سه سرباز سفید باکیفیت برای ورود به WATCHLIST.

    این فیلتر:
    - سیگنال خرید نیست
    - مجوز ورود نیست
    - صرفاً یک الگوی کندلی صعودی معتبر را شناسایی می‌کند

    طراحی:
    - بدون وابستگی به دامنه ثابت مثبت/منفی بازار
    - استفاده از نسبت بدنه به دامنه کندل
    - کنترل سایه بالایی
    - کنترل توالی بسته‌شدن
    - کنترل کیفیت کندل سوم
    ================================================================
    */


    if(typeof [ih]=="undefined")
        return false;

    if([ih].length<5)
        return false;


    // ------------------------------------------------
    // کندل‌ها
    //
    // [ih][0] = آخرین کندل
    // [ih][1] = یک کندل قبل
    // [ih][2] = دو کندل قبل
    // ------------------------------------------------

    var c0=[ih][0];
    var c1=[ih][1];
    var c2=[ih][2];


    if(
        typeof c0=="undefined" ||
        typeof c1=="undefined" ||
        typeof c2=="undefined"
    )
        return false;


    // ------------------------------------------------
    // OHLC
    // ------------------------------------------------

    var o0=c0.POpening;
    var h0=c0.PriceMax;
    var l0=c0.PriceMin;
    var cl0=c0.PClosing;

    var o1=c1.POpening;
    var h1=c1.PriceMax;
    var l1=c1.PriceMin;
    var cl1=c1.PClosing;

    var o2=c2.POpening;
    var h2=c2.PriceMax;
    var l2=c2.PriceMin;
    var cl2=c2.PClosing;


    if(
        o0<=0 || o1<=0 || o2<=0 ||
        h0<=0 || h1<=0 || h2<=0 ||
        l0<=0 || l1<=0 || l2<=0 ||
        cl0<=0 || cl1<=0 || cl2<=0
    )
        return false;


    // ------------------------------------------------
    // دامنه
    // ------------------------------------------------

    var r0=h0-l0;
    var r1=h1-l1;
    var r2=h2-l2;


    if(r0<=0 || r1<=0 || r2<=0)
        return false;


    // ------------------------------------------------
    // بدنه
    // ------------------------------------------------

    var b0=Math.abs(cl0-o0);
    var b1=Math.abs(cl1-o1);
    var b2=Math.abs(cl2-o2);


    // ------------------------------------------------
    // سه کندل باید صعودی باشند
    // ------------------------------------------------

    var bull0=cl0>o0;
    var bull1=cl1>o1;
    var bull2=cl2>o2;


    if(!(bull0 && bull1 && bull2))
        return false;


    // ------------------------------------------------
    // بدنه باید نسبت مناسبی از کل دامنه باشد
    //
    // آستانه نسبتی است، نه درصد ثابت قیمت.
    // ------------------------------------------------

    var bodyRatio0=b0/r0;
    var bodyRatio1=b1/r1;
    var bodyRatio2=b2/r2;


    if(
        bodyRatio0<0.50 ||
        bodyRatio1<0.50 ||
        bodyRatio2<0.50
    )
        return false;


    // ------------------------------------------------
    // هر بسته شدن بالاتر از قبلی
    // ------------------------------------------------

    if(
        cl1<=cl2 ||
        cl0<=cl1
    )
        return false;


    // ------------------------------------------------
    // باز شدن کندل جدید نباید بیش از حد از بدنه
    // کندل قبلی فاصله گرفته باشد.
    //
    // برای بازارهایی که گپ واقعی ندارند،
    // شرط به صورت نسبتی تعریف شده است.
    // ------------------------------------------------

    var upperBody1=Math.max(o1,cl1);
    var lowerBody1=Math.min(o1,cl1);

    var upperBody2=Math.max(o2,cl2);
    var lowerBody2=Math.min(o2,cl2);


    var open0InsidePrevious=
        o0>=lowerBody1 &&
        o0<=upperBody1;

    var open1InsidePrevious=
        o1>=lowerBody2 &&
        o1<=upperBody2;


    if(!open0InsidePrevious || !open1InsidePrevious)
        return false;


    // ------------------------------------------------
    // سایه بالایی
    //
    // سایه بزرگ می‌تواند نشانه فشار فروش در سقف باشد.
    // ------------------------------------------------

    var upperWick0=h0-cl0;
    var upperWick1=h1-cl1;
    var upperWick2=h2-cl2;


    if(upperWick0/b0>0.45)
        return false;

    if(upperWick1/b1>0.45)
        return false;

    if(upperWick2/b2>0.45)
        return false;


    // ------------------------------------------------
    // کندل سوم نباید نسبت به دو کندل قبل
    // بیش از حد انفجاری باشد.
    //
    // هدف:
    // حذف بخشی از حرکت‌های دیرهنگام و فرسوده.
    // ------------------------------------------------

    var avgBody=(b1+b2)/2;

    if(b0>avgBody*2.5)
        return false;


    // ------------------------------------------------
    // رشد سه کندل باید منطقی باشد.
    // جلوگیری از سیگنال‌های بیش از حد کشیده.
    // ------------------------------------------------

    var totalMove=(cl0-o2)/o2;

    if(totalMove>0.20)
        return false;


    return true;

}()
```

# WS-3 چه چیزی به ما می‌گوید؟

اگر خروجی بدهد، می‌گوید:

> «در سه جلسه اخیر، ساختار کندلی نشان‌دهنده غلبه متوالی خریداران است و حرکت صرفاً به خاطر سه کندل سبز ضعیف شناسایی نشده؛ بلکه کیفیت بدنه، ترتیب بسته‌شدن و سایه‌ها نیز مناسب بوده است.»

این می‌تواند نشان‌دهنده یکی از این حالت‌ها باشد:

### حالت ۱ — شروع حرکت

سهم قبل از این سه کندل در فاز تراکم یا کف بوده و اکنون خریداران کنترل را به دست گرفته‌اند.

**این حالت برای ما بسیار جذاب است.**

### حالت ۲ — ادامه روند

سهم قبلاً صعودی بوده و سه سرباز صرفاً ادامه روند را نشان می‌دهند.

این هم مثبت است، ولی لزوماً فرصت اولیه نیست.

### حالت ۳ — اواخر حرکت

سهم قبلاً مقدار زیادی رشد کرده و سه کندل قدرتمند در انتهای روند ساخته است.

اینجا الگو می‌تواند حتی **هشدار دیر رسیدن** باشد.

بنابراین WS-3 به تنهایی نمی‌گوید:

> «بخر.»

بلکه می‌گوید:

> **«این حرکت کندلی ارزش بررسی دارد.»**

# فیلتر دوم

# **MSR — Morning Star Reversal Watchlist**

حالا الگوی کاملاً متفاوتی داریم.

Three White Soldiers بیشتر به **قدرت خرید متوالی** نگاه می‌کند.

Morning Star به دنبال این است که ببیند:

**فشار فروش → کاهش قدرت فروشنده → بازگشت خریداران**

اتفاق افتاده یا نه.

در نسخه‌ای که می‌نویسم، یک اشتباه رایج را مرتکب نمی‌شوم:

در بازارهایی که گپ واقعی کم است، اگر شرط کنیم حتماً بین تمام کندل‌ها Gap وجود داشته باشد، بخش بزرگی از الگوهای باارزش حذف می‌شوند.

پس Morning Star را **ساختاری** تشخیص می‌دهیم.

# MSR چه چیزی را شکار می‌کند؟

ساختار ایده‌آل:

```text
        فشار فروش
            ↓

        ███████
        ███████       ← کندل نزولی بزرگ
           █
           █           ← کندل کوچک / تردید
          ░

             ███████
             ███████   ← خریداران برگشته‌اند
             ███████
```

از نظر روان‌شناسی:

**کندل اول:** فروشنده هنوز کنترل دارد.

**کندل دوم:** فروشنده دیگر نمی‌تواند همان قدرت قبلی را حفظ کند.

**کندل سوم:** خریدار وارد شده و بخش قابل توجهی از افت را پس گرفته است.

این دقیقاً همان چیزی است که Morning Star را برای Watchlist جالب می‌کند.

# آیا ترکیب این فیلترها با D4C ایده خوبی است؟

**بله؛ اتفاقاً اینجا معماری فیلترهای ما جالب می‌شود.**

چون این چهار دسته داده یک چیز واحد را اندازه نمی‌گیرند.

مثلاً:

### D4C

می‌گوید:

> مومنتوم در زیر سطح قیمت در حال تغییر است.

### MSR

می‌گوید:

> رفتار کندل نشان می‌دهد فروشنده در حال از دست دادن کنترل است و خریدار برگشته.

### WS-3

می‌گوید:

> خریداران نه فقط برگشته‌اند، بلکه حداقل سه جلسه متوالی قدرت خود را حفظ کرده‌اند.

و بعد فیلترهای عملیاتی قبلی:

### RRE / SRS / سایر فیلترهای آنلاین

می‌توانند بگویند:

> این تغییر در مومنتوم و کندل اکنون در **معاملات واقعی و رفتار تابلو** نیز تأیید شده است.

این بسیار بهتر از این است که فقط بگوییم:

> «RSI واگرایی داده، پس بخر.»

# حتی یک نکته مهم‌تر

من **WS-3 را از MSR بهتر یا بدتر نمی‌دانم**؛ اینها دو مرحله متفاوت را می‌توانند شکار کنند.

### Morning Star

می‌تواند زودتر ظاهر شود:

**«فروشنده در حال شکست خوردن است.»**

### Three White Soldiers

معمولاً دیرتر ظاهر می‌شود:

**«خریدار پیروزی خود را در چند جلسه متوالی نشان داده است.»**

پس اگر هدف Watchlist باشد:

**MSR = Early Reversal Radar**

**WS-3 = Confirmed Buying-Pressure Radar**

و این تفاوت بسیار ارزشمند است.

---

## نظر نهایی من درباره تصمیم تو

تصمیم تو برای اینکه این فیلترها **مجوز خرید صادر نکنند** و صرفاً Watchlist بسازند، به نظرم تصمیم درستی است.

اتفاقاً برای الگوهای تکنیکال این رویکرد را ترجیح می‌دهم.

چون یک الگوی کندلی به تنهایی نمی‌داند:

* سهم چقدر نقدشونده است؛
* مقاومت بعدی کجاست؛
* سابقه گیرکردن دارد یا نه؛
* چه مقدار شناوری دارد؛
* پول حقیقی چه رفتاری داشته؛
* قدرت خریدار چگونه بوده؛
* آیا حرکت حاصل الگوریتم‌های معاملاتی است؛
* یا سهم در انتهای یک حرکت شارپی قرار گرفته است.

بنابراین:

**D4C / MSR / WS-3 = رادار**

و

**RRE / SRS / فیلترهای عملیاتی = فیلتر کیفیت و رفتار واقعی**

و در نهایت:

**تحلیل خودت = مجوز تصمیم**

این معماری از اینکه یک فیلتر واحد را مجبور کنیم همه‌چیز را حل کند، بسیار سالم‌تر است.

یک نکته فنی هم صریح بگویم: **کدهای بالا را بر اساس ساختار فیلترنویسی مورد استفاده در این زنجیره نوشته‌ام، اما قبل از استفاده واقعی باید روی چند صد سهم و چندین بازه تاریخی Backtest شوند.** مخصوصاً برای الگوهای کندلی، تعریف دقیق OHLC و ترتیب `[ih]` در نسخه نرم‌افزار تو باید با یک نمونه واقعی تأیید شود؛ من نمی‌خواهم صرفاً چون کد ظاهراً درست است، آن را «تضمین‌شده» جا بزنم.
