یک نکته بنیادی را هم در طراحی حفظ کرده‌ام: موج ۳ معمولاً قدرتمندترین بخش یک ایمپالس است، اما «قطعی» نیست. قواعد کلاسیک می‌گویند موج ۲ نباید بیش از ۱۰۰٪ موج ۱ را پس بگیرد و موج ۳ نمی‌تواند کوتاه‌ترین موج‌های ۱،۳،۵ باشد. خود Elliott Wave International نیز تأکید می‌کند که روش الیوت احتمالات را بالا می‌برد، نه اینکه نتیجه آینده را قطعی کند. ([Elliott Wave International][1])

# ۱. E3C-S

## Elliott Wave 3 Scanner

### «اسکنر آفلاین شکار کاندیدای موج سوم»

**نوع:** آفلاین
**کاربرد:** ساخت Watchlist
**هدف:** پیدا کردن سهم‌هایی که در دیتای تاریخی، ساختارشان با **پایان موج ۲ و آماده‌شدن برای موج ۳** سازگار است.

این فیلتر قرار نیست بگوید «موج ۳ قطعاً شروع شده».

می‌گوید:

> **«این سهم یک ساختار Wave 1 → Wave 2 قابل‌قبول دارد و ارزش بررسی برای شروع Wave 3 را دارد.»**

این تفکیک از نظر من حیاتی است.

### چرا آفلاین؟

چون برای پیدا کردن ساختار Wave 1 و Wave 2 باید تعداد زیادی کندل گذشته را بررسی کنیم و Pivotهای مناسب را پیدا کنیم. ابزارهای الیوت نیز برای شناسایی الگو به Pivotهای مناسب متکی هستند؛ حتی ابزار الیوت TradingView برای پیدا کردن الگوها صدها کندل گذشته را بررسی می‌کند. ([TradingView][2])

---

## شرایط اصلی E3C-S

فیلتر به‌صورت مفهومی این زنجیره را دنبال می‌کند:

```text
کف 0
  ↓
Wave 1
  ↓
Wave 2
  ↓
[منطقه بالقوه شروع Wave 3]
```

و برای معتبر ماندن شمارش:

### ۱. Wave 1 باید حرکت معنادار داشته باشد

نه یک نوسان کوچک تصادفی.

### ۲. Wave 2 باید Wave 1 را کامل باطل نکرده باشد

این یکی از قوانین بنیادی الیوت است. ([Elliott Wave International][1])

### ۳. اصلاح Wave 2 باید از نظر عمق منطقی باشد

فیبوناچی در اینجا **راهنما** است، نه قانون قطعی.

نواحی 38.2٪، 50٪ و 61.8٪ از نسبت‌های رایج اصلاحی هستند. ([Elliott Wave International][3])

### ۴. ترجیح با Wave 2 سالم است

اگر اصلاح تقریباً کل Wave 1 را بلعیده باشد، امتیاز Setup کاهش می‌یابد؛ حتی اگر هنوز از نظر قانون کلاسیک کاملاً باطل نشده باشد.

### ۵. ساختار باید با روند بزرگ‌تر تضاد شدید نداشته باشد

### ۶. فضای رشد بالای سر سهم بررسی شود

اگر درست بعد از محل احتمالی Wave 3 یک مقاومت بسیار سنگین وجود داشته باشد، امتیاز کم می‌شود.

### ۷. نقدشوندگی بررسی شود

سهمی که از نظر الیوت زیباست ولی خروج از آن دشوار است، برای سیستم تو کاندید طلایی نیست.

# امتیازدهی E3C-S

من این را **True/False ساده نمی‌کنم**.

یک مدل امتیازی بهتر است:

| بخش                |     وزن |
| ------------------ | ------: |
| ساختار Wave 1/2    |      25 |
| کیفیت اصلاح Wave 2 |      15 |
| Fib Confluence     |      10 |
| ساختار Pivot       |      10 |
| مومنتوم            |      10 |
| حجم                |      10 |
| نقدشوندگی          |      10 |
| فاصله از مقاومت    |      10 |
| **جمع**            | **100** |

و برای Watchlist:

**70+ → کاندید قابل بررسی**

**80+ → کاندید قوی**

**90+ → Golden Candidate**

اما این اعداد را باید بعداً با Backtest کالیبره کرد؛ امتیاز ۹۰ به‌خودی‌خود احتمال ۹۰٪ موفقیت نیست.

# کد E3C-S

```javascript
(Offline) xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx 

true==function()
{
    /*
    ================================================================
    E3C-S
    ELLIOTT WAVE 3 SCANNER

    OFFLINE WATCHLIST ENGINE

    هدف:
    پیدا کردن ساختار احتمالی:

        Wave 0 -> Wave 1 -> Wave 2 -> potential Wave 3

    این نسخه:
    - سیگنال خرید نیست
    - مجوز ورود نیست
    - برای ساخت Watchlist استفاده می‌شود
    - بر اساس Pivotهای تاییدشده کار می‌کند
    - قانون ابطال Wave 2 را رعایت می‌کند
    - عمق اصلاح Wave 2 را بررسی می‌کند
    - کیفیت ساختاری و نقدشوندگی را لحاظ می‌کند

    ================================================================
    */

    if(typeof [ih]=="undefined")
        return false;

    if([ih].length<80)
        return false;


    var N=Math.min([ih].length,120);

    var P=[];
    var H=[];
    var L=[];
    var V=[];


    for(var i=0;i<N;i++)
    {
        P[i]=[ih][i].PClosing;
        H[i]=[ih][i].PriceMax;
        L[i]=[ih][i].PriceMin;
        V[i]=[ih][i].QTotTran5J;

        if(P[i]<=0 || H[i]<=0 || L[i]<=0)
            return false;
    }


    // ------------------------------------------------
    // Pivot Low / High
    // ------------------------------------------------

    var isLow=function(i)
    {
        if(i<3 || i>N-4)
            return false;

        return(
            L[i]<=L[i-1] &&
            L[i]<=L[i-2] &&
            L[i]<=L[i+1] &&
            L[i]<=L[i+2]
        );
    };


    var isHigh=function(i)
    {
        if(i<3 || i>N-4)
            return false;

        return(
            H[i]>=H[i-1] &&
            H[i]>=H[i-2] &&
            H[i]>=H[i+1] &&
            H[i]>=H[i+2]
        );
    };


    // ------------------------------------------------
    // پیدا کردن آخرین Pivot Low
    // ------------------------------------------------

    var p2=-1;
    var p1=-1;
    var p0=-1;


    for(var i=4;i<N-4;i++)
    {
        if(isLow(i))
        {
            if(p2==-1)
                p2=i;
            else if(p1==-1)
                p1=i;
            else
            {
                p0=i;
                break;
            }
        }
    }


    if(p0==-1 || p1==-1 || p2==-1)
        return false;


    /*
    ------------------------------------------------
    توجه:
    ترتیب زمانی در [ih] معکوس است.
    p0 قدیمی‌تر از p1 و p2 است.
    ------------------------------------------------
    */


    // ------------------------------------------------
    // Pivot High بین p0 و p1
    // ------------------------------------------------

    var wave1High=-1;

    for(var i=p1+1;i<p0;i++)
    {
        if(isHigh(i))
        {
            wave1High=i;
            break;
        }
    }


    if(wave1High==-1)
        return false;


    var wave0Price=L[p0];
    var wave1Price=H[wave1High];
    var wave2Price=L[p1];


    // ------------------------------------------------
    // Wave 1 باید مثبت و معنادار باشد
    // ------------------------------------------------

    var wave1Move=
        (wave1Price-wave0Price)/wave0Price;


    if(wave1Move<0.05)
        return false;


    // ------------------------------------------------
    // Wave 2 نباید از Origin Wave 1 عبور کند
    // ------------------------------------------------

    if(wave2Price<=wave0Price)
        return false;


    // ------------------------------------------------
    // Retracement
    // ------------------------------------------------

    var retracement=
        (wave1Price-wave2Price)/
        (wave1Price-wave0Price);


    if(retracement<=0 || retracement>=1)
        return false;


    // ------------------------------------------------
    // ناحیه ترجیحی
    // ------------------------------------------------

    var fibGood=
        retracement>=0.382 &&
        retracement<=0.786;


    // ------------------------------------------------
    // قیمت فعلی باید نزدیک انتهای Wave 2 باشد
    // ------------------------------------------------

    var current=P[0];

    var distanceFromWave2=
        Math.abs(current-wave2Price)/
        wave2Price;


    if(distanceFromWave2>0.10)
        return false;


    // ------------------------------------------------
    // مقاومت بالای سر:
    // آخرین High قبل از Wave 1
    // ------------------------------------------------

    var resistance=-1;

    for(var i=wave1High+1;i<N-4;i++)
    {
        if(isHigh(i))
        {
            resistance=H[i];
            break;
        }
    }


    var room=true;

    if(resistance>0)
    {
        var roomPercent=
            (resistance-current)/current;

        if(roomPercent<0.03)
            room=false;
    }


    if(!room)
        return false;


    // ------------------------------------------------
    // حجم:
    // میانگین حجم 10 کندل اخیر
    // در برابر 10 کندل مربوط به Wave 1
    // ------------------------------------------------

    var recentVol=0;
    var oldVol=0;

    for(var i=0;i<10 && i<N;i++)
        recentVol+=V[i];

    for(var i=wave1High;i<wave1High+10 && i<N;i++)
        oldVol+=V[i];


    recentVol/=10;
    oldVol/=10;


    var volumeStructure=
        recentVol>=oldVol*0.50;


    if(!volumeStructure)
        return false;


    // ------------------------------------------------
    // مومنتوم ساده:
    // قیمت فعلی نباید زیر Wave 2 تثبیت شده باشد.
    // ------------------------------------------------

    if(current<wave2Price)
        return false;


    // ------------------------------------------------
    // فاصله زمانی Wave 1 و Wave 2
    // ------------------------------------------------

    var wave1Duration=
        Math.abs(p0-wave1High);

    var wave2Duration=
        Math.abs(wave1High-p1);


    if(wave1Duration<3 || wave2Duration<3)
        return false;


    // ------------------------------------------------
    // امتیاز
    // ------------------------------------------------

    var score=0;


    // ساختار
    score+=25;


    // Fib
    if(fibGood)
        score+=15;
    else
        score+=5;


    // کیفیت موج 1
    if(wave1Move>=0.10)
        score+=10;
    else
        score+=5;


    // اصلاح سالم
    if(retracement>=0.50 && retracement<=0.65)
        score+=10;
    else
        score+=5;


    // نقدشوندگی
    var avgVol=0;

    for(var i=0;i<20 && i<N;i++)
        avgVol+=V[i];

    avgVol/=20;

    if(avgVol>0)
        score+=10;


    // حجم
    score+=10;


    // فضای مقاومت
    score+=10;


    // ساختار زمانی
    if(wave2Duration>=wave1Duration*0.30)
        score+=5;


    // تایید موقعیت فعلی
    score+=5;


    /*
    ------------------------------------------------
    حداقل کیفیت برای Watchlist
    ------------------------------------------------
    */

    return score>=75;

}()
```

# ۲. E3C-L

# Elliott Golden Launch

### «موتور آنلاین فعال‌شدن موج سوم»

این **فیلتر مهم‌تر** است.

E3C-S قبلی می‌گوید:

> «کدام سهم‌ها ارزش زیر نظر گرفتن دارند؟»

اما E3C-L می‌گوید:

> **«از بین ساختارهای مناسب، کدام سهم همین حالا دارد از منطقه Wave 2 خارج می‌شود؟»**

پس:

**E3C-S = شکارچی آفلاین**

**E3C-L = ماشه آنلاین**

---

## چه زمانی E3C-L خروجی بدهد؟

من نمی‌خواهم به محض اینکه قیمت ۰.۵٪ بالا رفت خروجی بدهد.

باید یک **Transition** اتفاق بیفتد.

یعنی:

### ۱. ساختار Wave 1 → Wave 2 قبلاً وجود داشته باشد.

### ۲. قیمت بالای کف Wave 2 باقی مانده باشد.

### ۳. قیمت شروع به عبور از مقاومت محلی کند.

### ۴. حجم جاری نسبت به حجم معمول افزایش یابد.

### ۵. قدرت خریدار افزایش یابد.

### ۶. مومنتوم مثبت شود.

### ۷. قیمت هنوز بیش از حد از Wave 2 دور نشده باشد.

این آخری خیلی مهم است.

من نمی‌خواهم E3C-L بعد از اینکه سهم مثلاً ۱۵٪ از کف Wave 2 فاصله گرفت تازه به تو بگوید:

> «Wave 3 شروع شد!»

آن موقع ممکن است بخش زیادی از حرکت از دست رفته باشد.

---

# کد E3C-L

```javascript

(Offline) xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

true==function()
{
    /*
    ================================================================
    E3C-L
    ELLIOTT GOLDEN LAUNCH

    ONLINE WAVE-3 TRIGGER

    هدف:
    شناسایی لحظه‌ای که یک ساختار احتمالی
    Wave 1 -> Wave 2
    شروع به Transition به Wave 3 می‌کند.

    این فیلتر:
    - آنلاین است
    - سیگنال خرید قطعی نیست
    - برای شکار Early Wave-3 Momentum طراحی شده
    - نقدشوندگی و حجم را لحاظ می‌کند
    - از شکست ساختار Wave 2 جلوگیری می‌کند
    ================================================================
    */


    if(typeof [ih]=="undefined")
        return false;

    if([ih].length<80)
        return false;


    var N=Math.min([ih].length,120);

    var P=[];
    var H=[];
    var L=[];
    var V=[];


    for(var i=0;i<N;i++)
    {
        P[i]=[ih][i].PClosing;
        H[i]=[ih][i].PriceMax;
        L[i]=[ih][i].PriceMin;
        V[i]=[ih][i].QTotTran5J;

        if(P[i]<=0 || H[i]<=0 || L[i]<=0)
            return false;
    }


    // ------------------------------------------------
    // Pivotها
    // ------------------------------------------------

    var isLow=function(i)
    {
        if(i<3 || i>N-4)
            return false;

        return(
            L[i]<=L[i-1] &&
            L[i]<=L[i-2] &&
            L[i]<=L[i+1] &&
            L[i]<=L[i+2]
        );
    };


    var isHigh=function(i)
    {
        if(i<3 || i>N-4)
            return false;

        return(
            H[i]>=H[i-1] &&
            H[i]>=H[i-2] &&
            H[i]>=H[i+1] &&
            H[i]>=H[i+2]
        );
    };


    var p2=-1;
    var p1=-1;
    var p0=-1;


    for(var i=4;i<N-4;i++)
    {
        if(isLow(i))
        {
            if(p2==-1)
                p2=i;
            else if(p1==-1)
                p1=i;
            else
            {
                p0=i;
                break;
            }
        }
    }


    if(p0==-1 || p1==-1 || p2==-1)
        return false;


    // ------------------------------------------------
    // Wave 1 High
    // ------------------------------------------------

    var w1=-1;

    for(var i=p1+1;i<p0;i++)
    {
        if(isHigh(i))
        {
            w1=i;
            break;
        }
    }


    if(w1==-1)
        return false;


    var wave0=L[p0];
    var wave1=H[w1];
    var wave2=L[p1];

    var current=P[0];


    // ------------------------------------------------
    // Wave 1 معتبر
    // ------------------------------------------------

    if(wave1<=wave0)
        return false;


    var wave1Move=
        (wave1-wave0)/wave0;


    if(wave1Move<0.05)
        return false;


    // ------------------------------------------------
    // Wave 2 نباید Origin را بشکند
    // ------------------------------------------------

    if(wave2<=wave0)
        return false;


    // ------------------------------------------------
    // Retracement
    // ------------------------------------------------

    var retracement=
        (wave1-wave2)/
        (wave1-wave0);


    if(retracement<=0 || retracement>=1)
        return false;


    // ------------------------------------------------
    // ناحیه اصلاحی مناسب
    // ------------------------------------------------

    if(
        retracement<0.382 ||
        retracement>0.786
    )
        return false;


    // ------------------------------------------------
    // قیمت باید واقعاً از Wave 2 فاصله گرفته باشد
    // اما هنوز بیش از حد فرار نکرده باشد.
    // ------------------------------------------------

    var recovery=
        (current-wave2)/
        wave2;


    if(recovery<0.01)
        return false;

    if(recovery>0.15)
        return false;


    // ------------------------------------------------
    // عبور از Highهای کوتاه‌مدت
    // ------------------------------------------------

    var localHigh=-1;

    for(var i=1;i<=12 && i<N;i++)
    {
        if(H[i]>current)
            localHigh=H[i];
    }


    /*
    اگر سقف نزدیک هنوز بالای قیمت است،
    Transition کامل نشده.
    */

    if(localHigh>0 && current<localHigh)
        return false;


    // ------------------------------------------------
    // حجم
    // ------------------------------------------------

    var currentVol=V[0];

    var avgVol=0;

    for(var i=1;i<=20 && i<N;i++)
        avgVol+=V[i];

    avgVol/=20;


    if(avgVol<=0)
        return false;


    var volumeRatio=
        currentVol/avgVol;


    if(volumeRatio<1.20)
        return false;


    // ------------------------------------------------
    // قدرت قیمت
    // ------------------------------------------------

    var closePosition=
        (current-L[0])/
        (H[0]-L[0]);


    if(H[0]==L[0])
        return false;


    if(closePosition<0.60)
        return false;


    // ------------------------------------------------
    // مومنتوم کوتاه مدت
    // ------------------------------------------------

    if(P[0]<=P[3])
        return false;


    if(P[0]<=P[5])
        return false;


    // ------------------------------------------------
    // نقدشوندگی
    // ------------------------------------------------

    var avgTrades=0;

    for(var i=1;i<=20 && i<N;i++)
    {
        if(typeof [ih][i].ZTotTran5J!="undefined")
            avgTrades+= [ih][i].ZTotTran5J;
    }

    avgTrades/=20;


    if(
        typeof [ih][0].ZTotTran5J!="undefined" &&
        avgTrades>0
    )
    {
        if([ih][0].ZTotTran5J<avgTrades*0.70)
            return false;
    }


    // ------------------------------------------------
    // عدم شکست ساختار
    // ------------------------------------------------

    if(current<=wave2)
        return false;


    // ------------------------------------------------
    // فاصله از Wave 1
    //
    // اگر کاملاً از Wave 1 عبور کرده،
    // دیگر Early Launch نیست.
    // ------------------------------------------------

    if(current>wave1*1.10)
        return false;


    return true;

}()
```

# اما یک نکته بسیار مهم درباره این دو کد

من عمداً آنها را **«نسخه اولیه قابل آزمایش»** می‌دانم، نه نسخه‌ای که ادعا کنم همین الآن با اجرای آن روی هر نرم‌افزار بورس ایران نتیجه بی‌نقص می‌دهد.

دلیلش این است که **فیلترنویس‌های مختلف امکانات و نام متغیرهای متفاوتی دارند** و تشخیص واقعی Elliott Wave نیازمند دسترسی مطمئن به تاریخچه Pivot، حجم و در حالت ایده‌آل داده‌های چندتایم‌فریمی است.

ضمن اینکه شمارش الیوت ذاتاً احتمالاتی است. منابع اصلی نیز صراحتاً آن را ابزاری برای تعیین احتمال می‌دانند، نه قطعیت. ([Elliott Wave International][3])

# چرا E3C-L را «طلایی» می‌نامم؟

نه به این معنی که همیشه درست است.

به این معنی که **چند منبع مستقل از اطلاعات را روی یک نقطه حساس جمع می‌کند.**

```text
                Wave 1
                   ↓
              Wave 2 اصلاح
```

# مهم‌ترین فیلتر من در این مجموعه

اگر بخواهم از بین دو فیلتر فقط یکی را برای استفاده عملی انتخاب کنم:

### 🥇 E3C-L — Elliott Golden Launch

### E3C-S → E3C-L

این معماری از یک فیلتر عظیم که بخواهد هم شمارش الیوت، هم بنیاد، هم تابلو و هم لحظه ورود را یکجا حل کند، بسیار منطقی‌تر است.

## و یک ارتقای بسیار مهم برای نسخه بعدی

من فعلاً **D4C را داخل کد E3C-L نچپاندم**. این عمدی است.

ولی برای نسخه بعدی، بهترین ارتقای E3C-L از نظر من این است:

**E3C-L + D4C Confluence**

یعنی اگر ساختار Wave 2 پایان یافته باشد **و همزمان MFI + CCI + RSI + MACD واگرایی صعودی بدهند**، امتیاز آن Setup جهش کند.

بعد اگر:

**حجم + قدرت خریدار + شکست مقاومت کوتاه‌مدت**

هم تأیید کنند، آن کاندید تبدیل شود به:

### **E3C-G — Elliott Golden Launch / High-Confluence**

این را من از اضافه کردن ده اندیکاتور تصادفی بسیار ارزشمندتر می‌دانم. چون در آن حالت داریم **ساختار + مومنتوم + حجم + رفتار قیمت + تابلو** را هم‌جهت می‌کنیم.

در منابع تخصصی الیوت نیز استفاده از مومنتوم و حجم به‌عنوان پشتیبان شمارش موج توصیه شده و کانال‌کشی پس از پایان موج‌های ۱ و ۲ برای ارزیابی هدف موج ۳ مطرح شده است. ([Elwave][4])

**پس برای بایگانی نهایی:**

| کد        | نام                                     | نوع                | نقش                            |
| --------- | --------------------------------------- | ------------------ | ------------------------------ |
| **E3C-S** | Elliott Wave 3 Scanner                  | آفلاین             | پیدا کردن کاندیدهای Wave 3     |
| **E3C-L** | Elliott Golden Launch                   | آنلاین             | شکار شروع حرکت Wave 3          |
| **E3C-G** | Elliott Golden Launch / High-Confluence | نسخه ارتقایی آینده | Wave 3 + واگرایی + حجم + تابلو |

و من فعلاً **E3C-G را به‌عنوان فیلتر سوم مستقل نمی‌سازم**؛ چون همین دو مرحله کافی‌اند و ساختن فیلتر سوم در این نقطه بیشتر میز کار را شلوغ می‌کند. اول E3C-S و E3C-L باید روی داده واقعی آزمایش شوند.
